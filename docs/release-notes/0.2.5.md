# Aula 0.2.5

A steadier study window, course creation you can pause and resume, and new figures you can explore with your tutor.

If you have Aula 0.2.0 or later, it updates itself. **If you still have Aula 0.1.x, install this version by hand this
one time:** download it below and install it over your copy (your courses and settings stay). Aula 0.1.x will say this
version's signature isn't valid, because since 0.2.0 Aula is signed with new keys.

## What's new
- **The study window no longer flickers** when you return to it. Select and copy text in lessons, exercises and the
  chat, and use the right-click menu to look up, translate or search a selection. The system cursor option is easier
  to find in Settings → Appearance and the command palette.
- **Course creation pauses if AI credit runs out or a longer usage limit is reached:** Aula explains the limit and
  shows when it renews, if known. Topics already written stay available to study, and you can resume later. Stopping
  waits for the other agents and closes their pending questions before offering resume.
- **Choose the language of a new course** next to its level, or let Aula pick it from your system languages. Set the
  default in Settings → General.
- **New figures:** pyramids, funnels, Venn diagrams and mind maps; structural formulas with functional groups;
  drawings with moving parts, sliders and step-by-step constructions; maps with real countries and journeys; and
  clearer chart labels. Guided tours circle the parts as each step is explained.
- **Mark and ask the tutor:** in lessons and practice, circle or highlight part of a diagram, drawing, labeled figure,
  map or structural formula, add a note and ask about it. The tutor receives the names of the parts you marked.
  These figures adapt code from [Sketchy](https://github.com/ddkbs/sketchy), by
  ddkbs, under the MIT license; the full credit and license travel with Aula in
  [THIRD_PARTY_NOTICES.md](https://github.com/luumlabs/aula/blob/v0.2.5/THIRD_PARTY_NOTICES.md).

**Course compatibility:** existing courses and older figures in saved chats and slides continue to open. Aula 0.2.4
cannot display every new figure, and saving a course there can discard fields added in 0.2.5. Keep courses that use
the new figures in 0.2.5 or later, and keep a backup before opening them in an older version.

**macOS signing:** 0.2.5 keeps Aula's current signing certificate and prepares the updater for a future release signed
with an Apple Developer ID certificate. **This version is not notarized.** A first manual installation still needs *Open Anyway*, as described below.

## Install

| System | Download | First launch |
| --- | --- | --- |
| macOS 13 or later (Apple Silicon and Intel) | `Aula-0.2.5-mac.dmg` | Drag Aula to *Applications*. It isn't notarized yet: try to open it, then go to *System Settings → Privacy & Security → Open Anyway* (on macOS 14 and earlier, right-click → Open). |
| Windows 10 and 11 (x64 and ARM) | `Aula-Setup-0.2.5.exe` | If SmartScreen appears: *More info → Run anyway*. |
| Linux x64 | `Aula-0.2.5-linux-x86_64.AppImage` · `Aula-0.2.5-linux-amd64.deb` | `chmod +x` the AppImage and open it, or `sudo apt install ./Aula-0.2.5-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.2.5-linux-arm64.AppImage` | `chmod +x` the AppImage and open it. |
| Android 8 or later | `Aula-0.2.5-android.apk` | Open the file on the phone and allow installing from that app when Android asks. It needs Aula running on your Mac or on a server. |
| Server (Docker, x64 and ARM64) | `ghcr.io/luumlabs/aula-server:0.2.5` | `docker run -d --name aula --restart unless-stopped --shm-size=1g -v aula-data:/data ghcr.io/luumlabs/aula-server:0.2.5`, then `docker logs aula`. |

All the changes are in the [CHANGELOG](https://github.com/luumlabs/aula/blob/v0.2.5/CHANGELOG.md).

# Aula 0.2.5

Una ventana de estudio sin parpadeos, cursos cuya creación puedes pausar y reanudar, y nuevas figuras para explorar con
tu tutor.

Si tienes Aula 0.2.0 o posterior, se actualiza sola. **Si todavía tienes Aula 0.1.x, instala esta versión a mano esta
única vez:** descárgala abajo e instálala encima de tu copia (tus cursos y ajustes se quedan). Aula 0.1.x dirá que la
firma de esta versión no es válida, porque desde la 0.2.0 Aula va firmada con claves nuevas.

## Lo nuevo
- **La ventana de estudio ya no parpadea** cuando vuelves a ella. Selecciona y copia texto de las lecciones, los
  ejercicios y el chat, y usa el menú del botón derecho para consultar, traducir o buscar una selección. La opción de
  cursor del sistema se encuentra más fácilmente en Ajustes → Apariencia y en la paleta de comandos.
- **La creación del curso se pausa si se agota el saldo de la IA o se alcanza un límite de uso prolongado:** Aula
  explica el límite e indica cuándo se renueva, si se sabe. Los temas ya escritos siguen disponibles para estudiar y
  puedes reanudar después. Al detener, espera a los demás agentes y cierra sus preguntas pendientes antes de ofrecer
  reanudar.
- **Elige el idioma de un curso nuevo** junto a su nivel, o deja que Aula lo escoja de los idiomas del sistema. El
  valor por defecto está en Ajustes → General.
- **Nuevas figuras:** pirámides, embudos, diagramas de Venn y mapas mentales; fórmulas estructurales con grupos
  funcionales; dibujos con piezas que se mueven, deslizadores y construcciones paso a paso; mapas con países reales y
  recorridos; y etiquetas de gráficos más claras. Los recorridos guiados rodean las partes mientras se explica cada
  paso.
- **Marca y pregunta al tutor:** en las lecciones y la práctica, rodea o resalta una parte de un diagrama, dibujo,
  figura con etiquetas, mapa o fórmula estructural, añade una nota y pregunta sobre ella. El tutor recibe los nombres
  de las partes que has marcado. Estas figuras adaptan código de
  [Sketchy](https://github.com/ddkbs/sketchy), de ddkbs, con licencia MIT; el crédito completo y la licencia acompañan a
  Aula en [THIRD_PARTY_NOTICES.md](https://github.com/luumlabs/aula/blob/v0.2.5/THIRD_PARTY_NOTICES.md).

**Compatibilidad de los cursos:** siguen abriéndose los cursos existentes y las figuras antiguas de los chats y las
diapositivas guardados. Aula 0.2.4 no puede mostrar todas las figuras nuevas, y guardar un curso allí puede descartar
campos añadidos en la 0.2.5. Mantén los cursos que usen las figuras nuevas en la 0.2.5 o posterior, y guarda una copia
antes de abrirlos en una versión anterior.

**Firma de macOS:** la 0.2.5 conserva el certificado de firma actual de Aula y prepara el actualizador para una futura
versión firmada con un certificado Developer ID de Apple. **Esta versión no está notarizada.** La primera instalación a mano sigue necesitando *Abrir
igualmente*, como se indica abajo.
