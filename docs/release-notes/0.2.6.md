# Aula 0.2.6

Aula for Mac is now signed with an Apple Developer ID and notarized, you can save figures as images, and course
creation copes better with credit limits.

If you have Aula 0.2.0 or later, it updates itself. On a Mac, copies from 0.2.0 to 0.2.4 update to 0.2.5 first and
then to 0.2.6. **If you still have Aula 0.1.x, install this version by hand this one time:** download it below and
install it over your copy (your courses and settings stay). Aula 0.1.x will say this version's signature isn't valid,
because since 0.2.0 Aula is signed with new keys.

**On a Mac, once after updating:** the first time 0.2.6 opens, macOS asks for your Mac password so Aula can use
“Aula Safe Storage”, where your keys and study-platform sessions are kept. Type it and choose *Always Allow*. If you
choose *Deny*, nothing is lost: your saved keys just stay locked. Click *Aula can’t open the keychain* in the sidebar,
then *Reopen Aula*, and choose *Always Allow* this time.

## What's new
- **Signed and notarized for Mac:** Aula now carries an Apple Developer ID signature and is notarized by Apple, so a
  copy you download opens straight away, with no more *Open Anyway*.
- **Save figures as images** from their *Export figure* menu in the desktop app: chemical drawings as SVG or PNG,
  drawings and diagrams as PNG. The image shows the whole figure whatever the zoom, with the current step, the
  highlighting and the formulas.
- **Retrying a failed question keeps its images and documents**, also when the question is only an image.
- **Course creation:** running out of credit with Claude Code or OpenCode now pauses it with *Resume*, as with an API
  key. Resuming a course stopped during planning no longer duplicates topics, deleting a course while it's being
  created stops it cleanly, and *Resume* says why if it fails.
- **Scanned PDFs import again:** the installers no longer leave out a file the OCR needs (it broke imports in the
  Linux AppImage).
- **Diagram steps no longer give away what comes next:** shapes that aren't revealed yet stay hidden.
- **Your keys are never saved unencrypted on macOS or Windows:** if the keychain isn't available, Aula waits until it
  is.
- **A new README** with a short demo and screenshots; installing and the full list of features have their own pages.

## Install

On a Mac, download `Aula-0.2.6-mac.dmg`. The `Aula-0.2.5-mac.*` files on this page are only for older copies that
update through 0.2.5.

| System | Download | First launch |
| --- | --- | --- |
| macOS 13 or later (Apple Silicon and Intel) | `Aula-0.2.6-mac.dmg` | Drag Aula to *Applications* and open it. If you already had Aula, macOS asks once for your Mac password for “Aula Safe Storage”: choose *Always Allow*. |
| Windows 10 and 11 (x64 and ARM) | `Aula-Setup-0.2.6.exe` | Aula isn't code-signed for Windows yet. If SmartScreen appears: *More info → Run anyway*. |
| Linux x64 | `Aula-0.2.6-linux-x86_64.AppImage` · `Aula-0.2.6-linux-amd64.deb` | `chmod +x` the AppImage and open it, or `sudo apt install ./Aula-0.2.6-linux-amd64.deb`. |
| Linux ARM64 | `Aula-0.2.6-linux-arm64.AppImage` | `chmod +x` the AppImage and open it. |
| Android 8 or later | `Aula-0.2.6-android.apk` | Open the file on the phone and allow installing from that app when Android asks. It needs Aula running on your Mac or on a server. |
| Server (Docker, x64 and ARM64) | `ghcr.io/luumlabs/aula-server:0.2.6` | `docker run -d --name aula --restart unless-stopped --shm-size=1g -v aula-data:/data ghcr.io/luumlabs/aula-server:0.2.6`, then `docker logs aula`. |

All the changes are in the [CHANGELOG](https://github.com/luumlabs/aula/blob/v0.2.6/CHANGELOG.md).

# Aula 0.2.6

Aula para Mac ya va firmada con un Developer ID de Apple y notarizada, puedes guardar las figuras como imagen y la
creación de cursos lleva mejor los límites de saldo.

Si tienes Aula 0.2.0 o posterior, se actualiza sola. En un Mac, las copias de la 0.2.0 a la 0.2.4 se actualizan
primero a la 0.2.5 y luego a la 0.2.6. **Si todavía tienes Aula 0.1.x, instala esta versión a mano esta única vez:**
descárgala abajo e instálala encima de tu copia (tus cursos y ajustes se quedan). Aula 0.1.x dirá que la firma de esta
versión no es válida, porque desde la 0.2.0 Aula va firmada con claves nuevas.

**En un Mac, una vez tras actualizar:** la primera vez que se abre la 0.2.6, macOS te pide la contraseña de tu Mac para
que Aula pueda usar «Aula Safe Storage», donde se guardan tus claves y tus sesiones de las plataformas. Escríbela y
elige *Permitir siempre*. Si eliges *Denegar*, no se pierde nada: tus claves guardadas solo quedan bloqueadas. Pulsa
*Aula no puede abrir el llavero* en la barra lateral, luego *Reabrir Aula*, y esta vez elige *Permitir siempre*.

## Lo nuevo
- **Firmada y notarizada para Mac:** Aula lleva ahora una firma Developer ID de Apple y está notarizada por Apple, así
  que una copia descargada se abre directamente, sin *Abrir igualmente*.
- **Guarda las figuras como imagen** desde su menú *Exportar figura* en la app de escritorio: los dibujos químicos en
  SVG o PNG, y los dibujos y los diagramas en PNG. La imagen muestra la figura entera sea cual sea el zoom, con el paso
  actual, lo resaltado y las fórmulas.
- **Reintentar una pregunta que falló conserva sus imágenes y documentos**, también si la pregunta es solo una imagen.
- **Creación de cursos:** si te quedas sin saldo con Claude Code u OpenCode, ahora se pausa con *Reanudar*, como con
  una clave de API. Reanudar un curso detenido mientras se planificaba ya no duplica temas, borrar un curso mientras se
  crea lo detiene limpiamente y *Reanudar* dice por qué si falla.
- **Los PDF escaneados se importan de nuevo:** los instaladores ya no dejan fuera un archivo que necesita el OCR
  (fallaba en la AppImage de Linux).
- **Los pasos de un diagrama ya no adelantan lo que viene:** las formas que aún no se han mostrado siguen ocultas.
- **Tus claves nunca se guardan sin cifrar en macOS ni en Windows:** si el llavero no está disponible, Aula espera a
  que lo esté.
- **Un README nuevo** con una demo corta y capturas; la instalación y la lista completa de funciones tienen sus propias
  páginas.
